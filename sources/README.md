# Источники

## Тренажёры тактики (GitHub)
- [Pádel Táctico](https://miguelsosatr.github.io/padel-tactics/) — игра-тренажёр: каждый удар в розыгрыше — выбор с объяснением (испанский).
- [Padel Eyes](https://nikbeznosikov.github.io/padel-eyes/) — тактические задачки в 3D глазами игрока.
- [PadelTactics](https://frankoosterling92.github.io/PadelTactics/) — веб-приложение по тактике.
- [padelCourt](https://mfermin.github.io/padelCourt/) — доска для рисования схем.

## Тесты и квизы
- [Padel Eyes](https://nikbeznosikov.github.io/padel-eyes/) — «выбери удар» в 3D из глаз игрока, потом показывается розыгрыш и разбор (англ.).
- [Pádel Táctico](https://miguelsosatr.github.io/padel-tactics/) — розыгрыш по шагам, каждый ответ: оптимально / зависит / ошибка (исп.).
- [Padel Regel-Quiz](https://padel-quiz-ashy.vercel.app) — тест по правилам DPV/FIP (нем.).
- [PadelQuizz](https://danifcs99.github.io/PadelQuizz/) — общий квиз о паделе (исп.).

## Анализ видео и данные
- [padel_analytics](https://github.com/Joao-M-Silva/padel_analytics) — ИИ-анализ матча: трекинг игроков и мяча, распознавание ударов.
- [PadelVic](https://github.com/UPC-ViRVIG/PadelVic), [Padel-Shot-Classification](https://github.com/guillecartes/Padel-Shot-Classification-and-Dataset) — датасеты для распознавания ударов.
