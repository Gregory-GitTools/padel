# Падел — материалы

Личная коллекция материалов по паделу: техника ударов, тактика, упражнения, ссылки. Сайт сделан в первую очередь для телефона, с озвучкой.

- **[academy.html](academy.html)** — Академия: все 24 удара коротко — когда играть, фишка, частая ошибка; фильтр по зонам, озвучка «слушать подряд».
- **[quiz.html](quiz.html)** — тест «Что играть?»: 20 ситуаций на корте в двух наборах (основы и по роликам The Padel School), мяч летит после ответа, короткое «почему».
- **[index.html](index.html)** — комикс «Падел в картинках»: 11 ударов по 3 кадра, тактические схемы, тренировка на 60 минут. Открыть двойным щелчком в браузере.
- **[score.html](score.html)** — счётчик матча: длинная (больше/меньше), короткая (золотой мяч) и новые правила (Star Point). Показывает счёт, кто подаёт и с какого поля; на решающем мяче — выбор поля приёма. Форматы: 3 сета, 1 сет, про-сет, Fast4, супер-тай-брейк. Учёт подач: 1-я/2-я, двойные ошибки, статистика по игрокам. Голосом объявляет счёт.
- **[tournament.html](tournament.html)** — турнир: Американо (4/8/12/16 игроков), Мексикано, Командное американо; счёт «до N очков» или «по времени» с таймером; таблица и идеи других форматов.
- **[techniques/](techniques/)** — заметки по технике ударов.
- **[tactics/](tactics/)** — тактика: позиции, схемы, разборы розыгрышей.
- **[drills/](drills/)** — упражнения и планы тренировок.
- **[sources/](sources/)** — ссылки на видео, статьи, приложения и проекты.
